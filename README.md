# vosracines.fr

Site statique (GitHub Pages) de Vos Racines : livres de famille écrits à partir des archives.

- `index.html` : la page ; paiement par liens Stripe (Payment Links), à renseigner dans `STRIPE` en bas du fichier. Codes promo : à activer sur chaque lien dans Stripe (« Autoriser les codes promotionnels »).
- `mentions-legales.html`, `cgv.html`, `confidentialite.html` : brouillons ; les points à valider s'affichent en ajoutant `#brouillon` à l'adresse.
- `img/` : extraits d'un livre réalisé, noms changés.
- Copie de travail sur HQ : `~/Agentic/projets/vosracines/site`.
- Tant que le site est un prototype : balise `noindex`.
